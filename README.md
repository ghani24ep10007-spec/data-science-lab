## Roadmap 6 Bulan

- **P1 (Bulan 1–2) — Fondasi:** DS-001, DS-002, mulai DS-010. Python, pandas, SQL, statistik.
- **P2 (Bulan 2–4) — Classical ML:** DS-003, DS-004, DS-005, Kaggle. Pipeline, evaluasi benar, deploy pertama.
- **P3 (Bulan 4–5) — Specialisasi:** DS-006, DS-007, DS-008, DS-009. Pilih 2 jalur favorit.
- **P4 (Bulan 5–6) — Modern Stack:** DS-011 (RAG), rapikan GitHub & portofolio.

## Kenapa list ini cocok untuk Junior DS?

1. **Fondasi terlihat** — EDA, statistik, SQL dulu, bukan langsung deep learning.
2. **End-to-end** — tiap proyek sampai tahap evaluasi + artefak publik (notebook/dashboard/API).
3. **Metrik yang benar** — PR-AUC untuk kelas imbang, backtest untuk time series, NDCG untuk recommender.
4. **Relevan pasar 2026** — ada jalur LLM/RAG yang sedang dicari, tapi di urutan terakhir agar fondasi kuat dulu.
5. **Bisa diverifikasi rekruter** — semua repo publik, README terstruktur, ada hasil yang bisa dibuka.
