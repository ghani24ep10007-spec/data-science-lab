PlannedPandasVisualisasi

DS-002

Analisis Statistik & A/B Testing

Beginner

Uji hipotesis pada data eksperimen nyata: uji-t, chi-square, power analysis, dan interpretasi hasil untuk keputusan bisnis.

PlannedStatistikSciPy
Deep Dive

Langkah

  1. Simulasi/ambil dataset eksperimen (mis. konversi web)
  2. Hitung ukuran efek, CI 95%, dan power test
  3. Bandingkan parametrik vs non-parametrik
  4. Simpulkan: signifikansi ≠ relevansi bisnis

Apa yang dipelajari

  • Fondasi inferensi statistik — bekal wajib sebelum ML
  • Menghindari jebakan p-hacking & multiple testing
SciPyStatsmodelsSeaborn

DS-003

Prediksi Churn Pelanggan

Intermediate

Klasifikasi pelanggan berisiko keluar: Logistic Regression sebagai baseline, lalu gradient boosting, dengan penanganan kelas tidak seimbang.

In ProgressKlasifikasiImbalanced
Deep Dive

Langkah

  1. EDA + feature engineering (RFM-like, tenure, usage)
  2. Baseline: Logistic Regression + kalibrasi probabilitas
  3. Model 2: XGBoost/LightGBM + SMOTE/class_weight
  4. Evaluasi: ROC-AUC, PR-AUC, recall on churners, business cost matrix
  5. Interpretasi dengan SHAP + rekomendasi retensi

Apa yang dipelajari

  • Metric selection untuk kelas imbang
  • Explainability & menerjemahkan model ke aksi bisnis
scikit-learnXGBoostimbalanced-learnSHAP

DS-007

Analisis Sentimen Ulasan Bahasa Indonesia

Intermediate

Klasifikasi sentimen (positif/netral/negatif) ulasan produk/aplikasi berbahasa Indonesia dari baseline lexicon ke TF-IDF+Linear hingga transformer.

In ProgressNLP
Deep Dive

Langkah

  1. Scraping/dataset publik + pelabelan (bisa weak supervision)
  2. Preprocessing: normalization, slang dictionary, stemming
  3. Baseline lexicon → TF-IDF + Logistic Regression

  5. Evaluasi macro-F1 + confusion matrix + error analysis

DS-009

Klasifikasi Citra dengan Transfer Learning

Intermediate

Klasifikasi gambar nyata (mis. penyakit daun / sampah) memakai CNN pretrained: frozen features lalu fine-tuning.

PlannedComputer Vision
Deep Dive
